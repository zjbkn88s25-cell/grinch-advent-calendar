# Grinch Advent Calendar – Website-Erklärung

## 1. Grundidee
Die Website ist der digitale Adventskalender und die gemeinsame Navigationsoberfläche für die Unterrichtsreihe.

Die Startseite zeigt:
- das verschneite Weihnachtsdorf,
- das Gebirge mit Höhle,
- die 6 Missionssymbole,
- feste Buttons für:
  - How does it work?
  - Teamwork
  - Christmas Words

Die Kinder suchen bzw. wählen ein Missionssymbol aus.
Danach folgt:
SYMBOL → CODE → STORY / LISTEN → TOPIC → MISSION → NEXT SYMBOL

## 5. Ablauf einer Story-Mission

Beispiel:

1. Kind klickt auf das Missionssymbol.
2. Die Website öffnet die Code-Eingabe.
3. Richtiger 5-stelliger Code:
   MISSION UNLOCKED!
4. Danach erscheint:
   - großes Storybild
   - großer LISTEN-Button
5. Der LISTEN-Button spielt die echte Sprachnachricht ab.
6. Danach:
   WHAT IS THE TOPIC?
7. Mögliche Antwortfelder:
   - Christmas Decorations
   - Christmas Feast
   - The Grinch as Santa Claus
   - Christmas Singing
8. Richtige Antwort:
   Mission öffnet sich.
9. Nach der Aufgabe:
   NEXT SYMBOL

## 6. Mission-Masterseite

Jede Mission soll dieselbe visuelle Struktur haben:

MISSION X

🚩 YOUR GOAL
kurzer englischer Satz

🎒 YOU NEED
Materialien immer mit Piktogrammen/Bildkarten

Beispiel:
- Whoville picture
- clue cards
- Sun
- Cloud
- Moon
- Star

Dann die Schritte:

1. 📖 READ
2. 🗣️ SHARE
3. ✋ PLACE
4. ✅ CHECK

Zusätzliche feste Symbole:

💡 HELP STATION
= Tippstation

✅ SOLUTION STATION
= Lösungsstation

🔎 NEXT SYMBOL
= nächstes Adventskalender-Symbol suchen

## 7. Christmas Words

Die Vocabulary-Seite zeigt alle Wörter einer Kategorie gleichzeitig.

Kategorien zunächst:
- Decorations
- Food

Die Kinder tippen direkt auf das Bild bzw. die Wortkarte.
Später kann dort die echte Aussprache als Audiodatei hinterlegt werden.

Keine deutsche Übersetzung auf der Kinderseite.

---

## 8. Designprinzipien

- 16:9, gut für digitale Tafel
- große Touch-Flächen
- englische Anweisungen
- immer Piktogramm + Text
- Storybilder dürfen sehr atmosphärisch sein
- Arbeitsseiten dagegen ruhig und klar
- immer gleiche Positionen für wiederkehrende Funktionen
- HELP = Glühbirne
- SOLUTION = Haken
- FIND = Lupe
- CODE = Schloss
- LISTEN = Lautsprecher / Play
- READ = Buch
- SHARE = Sprech-/Team-Symbol
