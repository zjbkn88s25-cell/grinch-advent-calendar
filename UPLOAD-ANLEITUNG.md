# GitHub upload - genau so

## 1. ZIP entpacken
Die ZIP nicht direkt bei GitHub hochladen.

## 2. Diese Dinge hochladen
Aus dem entpackten Ordner ALLES hochladen:
- `index.html`
- `styles.css`
- `script.js`
- Ordner `data`
- Ordner `images`
- Ordner `audio`
- `README.md`
- `UPLOAD-ANLEITUNG.md`

## 3. GitHub
Repository: `grinch-advent-calendar`

- Add file -> Upload files
- alle oben genannten Dateien und Ordner auswählen
- vorhandene Dateien durch die neuen ersetzen
- Commit changes

## 4. Prüfen
Im Repository müssen direkt sichtbar sein:
- `audio`
- `data`
- `images`
- `index.html`
- `script.js`
- `styles.css`

Wenn `images` oder `audio` fehlen, funktionieren Bilder/Audios auf der Website nicht.

## 5. GitHub Pages
Settings -> Pages
- Deploy from a branch
- main
- / (root)
